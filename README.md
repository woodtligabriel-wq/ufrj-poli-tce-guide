# ufrj-poli-tce-guide
Guia prático e oficial sobre prazos e assinaturas de TCE na Escola Politécnica da UFRJ

> Focado no caso real de início em 13/10 sem assinatura prévia

## TL;DR

- UFRJ assina SEMPRE por último
- Prazo oficial: 15 dias ANTES
- Não existe "15 dias depois"
- Fonte: CEG 12/2008 + Norma Poli

## Como usar este guia

1. Veja `docs/REGRA-OFICIAL.md` para a norma
2. Veja `templates/email-regularizacao.md` para copiar o e-mail
3. Veja `casos/caso-13-10.md` para entender o caso específico
